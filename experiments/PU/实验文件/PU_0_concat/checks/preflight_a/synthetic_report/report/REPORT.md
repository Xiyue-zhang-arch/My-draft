直接拼接两个64维特征为128维，不做平均、缩放或融合MLP。分类头从Linear64至4改成Linear128至4，多256参数。初始化两半为原64维权重的一半，训练后完全独立，不保留等权约束；只在eval初始化时与原均值函数等价。Dropout维数变化，因此旧均值与新拼接的差不能作为完全排除容量和随机掩码差异的纯操作效应。

单模态分别包含普通CNN和仅自身描述符调制版本，严禁读取另一模态信息。自己的4维描述符重复为8维只是匹配调制器结构。无预训练、无辅助头、单一最终交叉熵。

全部新旧方法共享原3200/800来源记录划分、来源定标、波形与物理描述符；63目标条件的实际输入哈希逐项匹配原等权实验。三个目标及噪声等权，五种子SD只反映训练随机性。

主比较为新concat_physical减新concat_plain，另比较四个单模态及原均值参照。没有重做原六组机制消融，因此不把旧均值结构的错频/统计量结论自动推广到新拼接。没有等容量双同模态对照，不把全部双模态收益归因为传感器互补。

历史目标已曝光，研究为探索性，固定已知轴承和工况不支持新轴承总体泛化。50轮最后模型不等于全部充分收敛。原PU_0和PU_1全部保留。
