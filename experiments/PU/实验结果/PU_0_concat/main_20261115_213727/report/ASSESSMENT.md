# PU_0直接拼接与单模态补充的结果判断

本轮已于2026-11-15 21:51:58完成并冻结。本文在完成后整理，只读取已冻结的汇总CSV、配置和独立审计，不增加训练、网络推理或测试条件。

## 实际完成的修改

两个分支在第三卷积块后接受物理描述符调制，再分别经过第四卷积块、池化和LayerNorm，各得到64维向量。双模态直接拼接成128维，经过Dropout和一个四分类线性层。没有平均、拼接后缩放或融合MLP。训练仍为单一融合分类损失，从头联合优化。

补充仅振动和仅电流实验，各包含无物理调制和自身物理调制版本。单模态不读取另一模态的波形或描述符。为保留原条件网络结构，自身四维描述符重复为八维。这样既可比较单模态与双模态，也可区分物理模块与新增传感器带来的性能变化。

新实验为六配置乘五种子，共30个新模型。每模型固定50轮、2500次优化器更新，不按验证或目标分数选轮。来源划分、预处理和训练集定标沿用当前PU_0。原PU_0等权有无物理调制的10个模型只引用已存630份预测，不新增训练或推理。

## 主要结果

表中为五个种子的均衡准确率均值和标准差，单位为百分比。干净终点先在每个种子内对三个目标工况等权平均。受扰终点还对四个振动信噪比和五个噪声实例平均。噪声只施加于振动，因此电流单模态两个终点相同。

| 方法 | 干净BA | 振动受扰BA |
|---|---:|---:|
| 仅振动，无物理调制 | 80.95 ± 1.25 | 76.15 ± 1.77 |
| 仅振动，自身物理调制 | 81.64 ± 0.76 | 77.08 ± 1.14 |
| 仅电流，无物理调制 | 56.56 ± 2.15 | 56.56 ± 2.15 |
| 仅电流，自身物理调制 | 57.87 ± 2.18 | 57.87 ± 2.18 |
| 双模态拼接，无物理调制 | 85.00 ± 2.50 | 80.47 ± 1.23 |
| 双模态拼接，联合物理调制 | 86.84 ± 2.62 | 82.36 ± 1.84 |
| 原等权，无物理调制，只读参照 | 85.05 ± 2.15 | 80.32 ± 0.95 |
| 原等权，联合物理调制，只读参照 | 90.79 ± 3.78 | 86.72 ± 2.21 |

数值按冻结汇总CSV的双精度值显示。原等权物理模型干净终点未舍入值为90.795%。

联合物理调制相对普通拼接，干净和受扰BA分别增加1.8450和1.8821个百分点，五个配对种子均为正差。物理拼接相对更强的物理振动单模态分别增加5.1983和5.2791个百分点，同样五个种子均为正差。因此，本轮支持物理调制对当前拼接系统有增益，也支持当前双模态系统优于所测试的单模态系统。

但是，物理拼接相对原等权物理模型分别下降3.9517和4.3654个百分点，五个配对种子均下降。无物理拼接相对原无物理等权仅变化负0.0533和正0.1494个百分点，正差种子分别为2/5和3/5。本轮不支持将直接拼接描述为原等权物理方案的性能改进。

## 低速工况仍是主要限制

物理拼接在N09_M07_F10上的干净BA为66.65 ± 4.68%，外圈、内圈和复合故障召回率分别为24.56%、50.52%和91.52%。原等权物理模型在同一工况的BA为79.51 ± 9.61%，外圈召回率为66.40%。直接拼接后，低速外圈召回率下降41.84个百分点。

另外两个工况的物理拼接干净BA分别为99.95 ± 0.05%和93.93 ± 3.53%。因此，总体平均分不能掩盖低速工况的失效，也不能表述为所有工况和类别均改善。

## 结论边界

1. 物理拼接比普通拼接增加了条件网络，当前差值同时包含描述符输入和模块容量的影响。本轮没有重做替代频率、普通统计量或仅自身描述符等双模态机制对照。原等权架构中的机制比较不能直接移植为拼接架构的证据。
2. 拼接分类头为128至4，较原64至4增加256个参数，Dropout作用维度也改变。虽然初始化时两半权重各取旧分类头权重的一半，且随后独立更新，但该比较仍不能唯一识别融合运算本身的因果影响。
3. 双模态模型比单模态模型有更多编码器和条件网络参数。本轮没有等容量双振动对照。因此，可以报告系统性能超过这些单模态基线，不能把全部差值唯一归因于传感器互补。
4. 五种子反映固定数据协议下的训练随机性。相同轴承跨工况、窗口相关性和历史目标曝光仍然存在，不能据此推断新轴承总体显著性。描述符也没有因此被验证为模态信息丰富度的测量值。
5. 固定50轮是统一训练预算，不代表全部模型已充分收敛。当前结果不足以解释拼接为何下降，不能把低速失效事后归咎于某个未经验证的机制。
