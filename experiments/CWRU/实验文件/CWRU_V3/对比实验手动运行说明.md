# V3 跨负载小样本对比实验手动运行说明

四种对比方法为 WDCNN、DRSN-CW、PG-RDGFN-adapted、AW_Hybrid-adapted。小样本纯干净批次每种方法 180 个新模型，合计 720 个。数据划分、子集和训练种子与对应的 V3 小样本实验配对。四种方法的小样本和全样本批次均已完成，可查阅 [V3 实验结果](../../实验结果/CWRU_V3/)。

每个方法单独一个结果目录，训练和选模全部锁定后才统一测试另外三个负载并生成报告。同一次运行只写一个新目录，不允许重复启动、覆盖或自动重试。

## 运行前

- 确认原始 CWRU 48 kHz 驱动端数据、`experiments/CWRU/实验结果/CWRU_V3/load_small_20261025_2017`、`experiments/CWRU/实验结果/CWRU_V3/run_20261022_2105/splits` 仍在原处；报告要读取原预测与固定划分。
- 确认 `D:\anaconda\envs\pytorch_GPU\python.exe` 与 NVIDIA CUDA 可用，电源连接稳定，避免系统睡眠。
- 以下命令从 `D:\Project\MY draft` 在 PowerShell 7 中运行。

## 先看计划（不训练、不测试）

```powershell
cd 'D:\Project\MY draft'
pwsh -NoProfile -File '.\experiments\CWRU\实验文件\CWRU_V3\start_load_comparisons.ps1' -Plan -Method WDCNN
```

把 `WDCNN` 换成 `DRSN_CW`、`PG_RDGFN_adapted` 或 `AW_Hybrid_adapted` 可分别查看另外三种方法；用 `-Plan -Method all` 可以看到哪些方法已完成、哪些还会跑。

## 全样本补充实验（--sample full / -Sample full）

除小样本外，同一入口可跑四个方法的**跨负载全样本**纯干净实验：每方法 4 个来源 × 5 个种子 = 20 个新模型、60 个组合。全样本没有训练子集，报告只有 12 方向等权与种子间 SD，不生成子集间波动表；对照的本文方法数值改取 `load_full_20261024_0950` 的纯干净部分只读复用。

```powershell
cd 'D:\Project\MY draft'
# 四个方法顺序跑完全样本（每个方法一个新目录 load_comparison_full_*）
pwsh -NoProfile -File '.\experiments\CWRU\实验文件\CWRU_V3\start_load_comparisons.ps1' -Method all -Sample full
# 只跑一个方法
pwsh -NoProfile -File '.\experiments\CWRU\实验文件\CWRU_V3\start_load_comparisons.ps1' -Method PG_RDGFN_adapted -Sample full
```

先看计划：`-Plan -Sample full`。全样本忽略 `-Ratio`。

## 按顺序处理待运行的方法

已跑完的方法自动跳过，其余方法按顺序逐个跑完，每个方法各写一个新目录：

```powershell
cd 'D:\Project\MY draft'
pwsh -NoProfile -File '.\experiments\CWRU\实验文件\CWRU_V3\start_load_comparisons.ps1' -Method all
```

行为说明：

- 启动器会跳过所有 `stage=complete` 的方法。当前保存的四种方法均已完成。
- 某方法若存在未完成目录（`paused`、`failed`、训练中断），该方法不新建目录，只提示用 `-Resume -Output <目录>` 处理，其余方法继续跑。
- 每个方法开始时打印 `[i/4] 方法 -> 新目录`，结束时打印 `[i/4] 方法 complete`；全部结束打印 `summary:`。
- 单卡顺序执行，不会并行；中途按 Ctrl+C 只中断当前方法，已完成目录保留。
- 全部成功退出码为 0，有失败或未完成则为 1。

## 一次手动跑一个方法（可选）

也可以按下面四条命令逐个手动执行（建议一次只开一个窗口，不要并行）：

```powershell
cd 'D:\Project\MY draft'

# 1) WDCNN
pwsh -NoProfile -File '.\experiments\CWRU\实验文件\CWRU_V3\start_load_comparisons.ps1' -Method WDCNN

# 2) DRSN-CW
pwsh -NoProfile -File '.\experiments\CWRU\实验文件\CWRU_V3\start_load_comparisons.ps1' -Method DRSN_CW

# 3) PG-RDGFN-adapted
pwsh -NoProfile -File '.\experiments\CWRU\实验文件\CWRU_V3\start_load_comparisons.ps1' -Method PG_RDGFN_adapted

# 4) AW_Hybrid-adapted
pwsh -NoProfile -File '.\experiments\CWRU\实验文件\CWRU_V3\start_load_comparisons.ps1' -Method AW_Hybrid_adapted
```

运行时先显示 `Output:` 后接结果目录，例如：

```
D:\Project\MY draft\experiments\CWRU\实验结果\CWRU_V3\load_comparison_small_WDCNN_20261103_161500
```

请记下该目录。训练窗口实时显示进度，同时写入该目录的 `training_console.log`；测试阶段逐模型登记。保持窗口打开，锁屏不等于允许睡眠。

也可以用 Python 直接指定目录（一行）：

```powershell
& 'D:/anaconda/envs/pytorch_GPU/python.exe' -X utf8 -B experiments/CWRU/实验文件/CWRU_V3/run_load_comparisons.py run --output 'D:/Project/MY draft/experiments/CWRU/实验结果/CWRU_V3/load_comparison_small_WDCNN_20261103_161500' --method WDCNN
```

## 只跑某一档预算（可选）

默认一次跑 10%/20%/50% 三档。若想先跑 10%，加 `-Ratio 0.1`（也可写 `10`、`10%`）：

```powershell
pwsh -NoProfile -File '.\experiments\CWRU\实验文件\CWRU_V3\start_load_comparisons.ps1' -Method WDCNN -Ratio 0.1
```

这样该目录只有 60 个模型、180 个组合；**同一方法的不同预算要分别开新目录**，不要把两次运行写进同一目录。全部预算覆盖仍需 10%、20%、50% 三次（或一次不加 `-Ratio`）。

## 查询进度

另开一个 PowerShell 窗口，把路径换成实际结果目录：

```powershell
cd 'D:\Project\MY draft'
pwsh -NoProfile -File '.\experiments\CWRU\实验文件\CWRU_V3\start_load_comparisons.ps1' -Status -Output 'D:\Project\MY draft\experiments\CWRU\实验结果\CWRU_V3\load_comparison_small_WDCNN_20261103_161500'
```

`trained_models` 是已完整保存的模型数，`active_epoch` 是当前模型已写入日志的轮数。`stage=complete` 才表示训练、测试和报告全部完成；`testing` 表示正在测试，`reporting` 表示正在检查和汇总，`failed` 表示中止并保留现场。

## 主动暂停与恢复

训练阶段可在另一个窗口发送暂停请求（换成实际目录）：

```powershell
pwsh -NoProfile -File '.\experiments\CWRU\实验文件\CWRU_V3\start_load_comparisons.ps1' -Pause -Output 'D:\Project\MY draft\experiments\CWRU\实验结果\CWRU_V3\load_comparison_small_WDCNN_20261103_161500'
```

发送请求不等于已经暂停。程序会完成当前模型、保存并登记后自然停止；用 `-Status` 确认 `stage=paused` 且 `pause_boundary_verified=True` 后再关闭电脑。

下次手动恢复仍用同一目录：

```powershell
pwsh -NoProfile -File '.\experiments\CWRU\实验文件\CWRU_V3\start_load_comparisons.ps1' -Resume -Output 'D:\Project\MY draft\experiments\CWRU\实验结果\CWRU_V3\load_comparison_small_WDCNN_20261103_161500'
```

恢复时会核对已完成模型、保存的划分和权重，跳过已完成模型。暂停只在训练阶段有效；一旦进入权重核验或目标测试，就不能用这种方式暂停恢复。

## 测试中断后的续测（仅限文件占用）

如果测试阶段因 `config.json` 被其他程序占用而报 `PermissionError`（WinError 5）中止，且训练与权重核验已完成、已测试模型是原计划前缀，可用续测入口从已保存权重补齐剩余预测：

```powershell
& 'D:/anaconda/envs/pytorch_GPU/python.exe' -X utf8 -B experiments/CWRU/实验文件/CWRU_V3/run_load_comparisons.py recover-testing --output 'D:\Project\MY draft\experiments\CWRU\实验结果\CWRU_V3\load_comparison_small_实际目录'
```

它只补测缺失模型，不重训、不重测已完成模型、不覆盖已有预测，完成后生成报告，并在 `config.json` 记录 `test_recovery` 并保留原 `error`。以下情况一律拒绝续测、必须保留现场：非文件占用类失败、权重未核验、已完成模型不是原计划前缀、预测文件缺失、已生成报告。

## 异常中断与实验边界

异常退出、断电、强行结束进程或训练失败，都不等同于已核验暂停。程序不会自动重试未完成模型，也不会恢复测试中断。遇到这些情况请保留输出目录、`config.json`、日志和未完成模型现场，先检查状态再决定，不要对同一目录执行 `run`。

进程互斥锁会阻止同时启动两套本实验；锁文件保留，但操作系统锁随进程退出释放。

报告会先对每个模型 12 个方向等权，再统计五种子与三子集的波动。不同负载、种子、子集不能当成独立轴承重复；已有全负载选参和历史测试曝光，因此不能声称严格未见目标域。四种对照的适配范围、PG 的额外转速信息和不同精度见 `COMPARISON_LOAD_PROTOCOL.md`；统一训练规则不代表它们都已经充分调优。

每个方法的报告都包含本文方法和数据单分支的只读对照行；四种方法之间的合并表需要人工汇总四个目录的 `REPORT.md` 或 `report/equal_12_directions_seed_mean_sd.csv`。
