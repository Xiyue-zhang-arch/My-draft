# ClassBD + WDCNN 代码来源和适配说明

作者仓库 https://github.com/asdvfghg/ClassBD ，锁定 commit `08530497e388ed691936f15d6c55267f277ed270`（2025-03-28）。`upstream/` 保存运行所需的作者原始文件，按 GitHub 文件原始字节获取；原仓库目录未发现 LICENSE 文件。作者的噪声数据、其他分类器与数据集加载器不用于本次干净实验。

`classbd_engine.py` 是项目适配代码，保留作者二次卷积、频率滤波、WDCNN 和三个损失项的计算公式。作者网络固定输入 2048 点，V3 先按既有父窗口划分，再在每个 24000 点父窗口内切 12 个 2048 点子窗口，最后一段从 21952 点开始、与上一段重叠 576 点。每个父窗口取 12 段预测概率的算术平均并只产生一个类别预测。训练损失使用父窗口平均概率；物理统计取各段均值。不得在切子段后重新随机划分。

适配变更：作者代码用 `nn.Parameter(loss.mean())` 返回两项物理统计，会切断对应梯度；适配器保留公式但不再创建新 Parameter，并在除数为零时加极小值。作者模型先 softmax，再传入 CrossEntropyLoss；适配器对 12 段概率求均值后以 log 概率计算 NLL。作者示例每个 batch 重建优化器和调度器；适配器沿用 V3 的固定优化器与调度规则。作者 UW 的参数每次重新初始化且未加入优化器，故此处保留其初值 -0.5 的固定权重，而不声称是可训练不确定性权重。删除的 fvcore 导入仅用于作者单文件运行时的复杂度演示，模型和损失计算不需要。

因此这是在作者实现基础上修复并适配的 ClassBD + WDCNN，不能称为作者源码原样运行或原文结果复现。超参数选自 V3 固定比较协议，不保证是该方法最优值。输入信号在 V3 的每父窗口标准化后切片。

验证（功能检查，不计正式实验）：两项物理损失分别单独反向传播，均在 ClassBD 模块参数上产生非零梯度；真实 0HP 来源 10%、子集 4101 数据按原固定划分一轮训练，训练 9 父窗口、验证 19 父窗口，保存加载及验证 CE 复算一致。GPU RTX 5060 Laptop，批量 32，FP32，该轮峰值已分配显存约 460 MiB，训练阶段约 1.11 秒；实际全程耗时须以正式记录为准。
