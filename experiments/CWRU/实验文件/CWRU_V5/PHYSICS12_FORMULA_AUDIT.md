## 1. 研究范围与来源

采用全频带解调，不新增载波选带。每个窗口都计算外圈、内圈、滚动体全部指标，不使用真实类别选择模板。12维结构为R、U、C、N各三项。R的滚动体基频为BSF，U、C、N的滚动体基频为2BSF。

新增C和N的主要来源：Zhenling Mo, Jianyu Wang, Heng Zhang, Qiang Miao. Weighted Cyclic Harmonic-to-Noise Ratio for Rolling Element Bearing Fault Diagnosis. IEEE Transactions on Instrumentation and Measurement, 69(2), 432–442, 2020. DOI: https://doi.org/10.1109/TIM.2019.2903615 。

[作者公开稿全文](https://www.researchgate.net/profile/Zhenling-Mo/publication/345468702_Weighted_Cyclic_Harmonic-to-Noise_Ratio_for_Rolling_Element_Bearing_Fault_Diagnosis/links/5fabb1c6a6fdcc331b9464d6/Weighted-Cyclic-Harmonic-to-Noise-Ratio-for-Rolling-Element-Bearing-Fault-Diagnosis.pdf)。公开稿12页，页眉仍有投稿模板占位文字；公式编号按此稿定位，不把作者稿当成已经对照过的出版定稿。

## 2. 已固定的工程规则

以下是本项目预先指定的处理规则，除明确说明外，不声称均来自原论文。

| 项目 | 固定规则 | 性质 |
|---|---|---|
| 窗口 | 当前48 kHz、24000点，0.5 s | 沿用实验 |
| 全频带 | 去均值后Hilbert解析信号，不新增载波带通 | 用户确定的简化 |
| 分辨率 | 保留原长度，原生FFT间隔2 Hz | 工程选择 |
| 包络重采样 | 不再复用旧的3 kHz降采样 | 防止降采样与平方先后次序改变SES |
| 两端裁剪 | 不再直接复用旧滤波后的75点裁剪 | 不存在原四带滤波；Hilbert边缘误差仍需功能检查 |
| 谱窗 | 首版不加Hann，采用矩形观测窗 | 避免把未修正的原阈值与Hann谱混用 |
| 补零 | 不做用于寻峰的FFT补零 | 不以插值网格冒充真实分辨率 |
| 直流及端点 | 特征排除DC和Nyquist；统计阈值不用于这两个特殊频点 | 避免特殊分布与直流泄漏 |
| 原始均方幅值 | 特征计算前可做窗口尺度归一化，必须与阈值所用信号同尺度 | 比值不应随幅值缩放改变 |
| 新数据集 | 更新采样率、轴承参数及窗口转速；规则保持一致 | 不承诺所有信号均适用 |

取消Hann的目的不是声称矩形窗更优。矩形窗存在泄漏；以后若改用Hann、Welch或多窗估计，需要重新配套噪声自由度与尺度，不能保留当前阈值就称严格沿用。

全频带Hilbert不是无限无偏的解调。边缘误差、其他旋转成分与非白背景都可能影响描述符；这些限制不因不选带而消失。

## 3. 原有R和U

R保留原“目标谱能量占比”定义，改在全频带平方包络谱计算，故不是与旧39维逐值相同的保留。

R的三种基频为BPFO、BPFI、BSF，每种h=1,…,6。目标半宽固定为max(2 Hz,0.015 h f0)，保留旧R的容差，不借用新指标2.5%就宣称完全一致。取各谐波区间并集，区间重叠不重复累加；分母取全体正频率且排除Nyquist的谱值之和。所有目标区须完整落在有效谱内，否则报告输入条件不满足，不悄悄改变阶次数。零输入输出R=0并记录，不对谱逐点抬底后再求比例。

U使用普通包络e=|Hilbert(x)|去均值后的线性自相关，以零延迟归一化，不加Hann，也不使用循环自相关。三组基频为BPFO、BPFI、2BSF。对k=1,2,3，在延迟k fs/f0附近搜索，半宽为max(1,0.02 k fs/f0)个采样点。只保留半宽内的正整数延迟，取峰后平均。取消旧低采样率实现中的固定±20点枚举上限，避免在48 kHz下人为截断搜索区。零能量输出U=0并记录。

R、U是本项目继承的工程指标，不能分别改名为原文RCC、WCER或EHNR。自相关与功率谱相关，不能称两份独立物理证据。

## 4. 新增C和N的搜索约定

三类基频为BPFO、BPFI、REFF=2BSF。容差参数固定沿用作者稿的delta=0.025。

关键区别：原文不是对第h阶直接使用±2.5% h f0的独立宽区间。它以基频容差作为每次递推步长的半宽，通过前一阶估计位置确定下一阶搜索区间；未通过原文噪声阈值的该阶使用区间中点递推。不得用旧特征代码的独立寻峰函数代替。

目标区间总宽固定为w=2 delta f0。左右背景各分成M=floor((0.5 f0-0.5 w)/w)个同宽区间；delta=0.025时M=9。背景统计取每个小区间的最大谱值，再对左右共2M项求算术平均，不是对原始谱点求均值，不是几何均值，也不是取整个背景的单一最大值。

CHNR采用10 log10(目标区最大值/背景小区间最大值的算术平均)。不以20 log10代替，也不先把SES再平方。

谐波上限固定为6阶，这是本项目工程上限，不是原文强制规定。每类从1阶顺序处理，执行原文的双阈值及连续两阶未检出停止规则。不能检查完6阶后跳过不显著阶继续找后面的孤立峰。保留的C是已检出正CHNR的和，N是对应数量，N=0时C=0。

以2BSF为基频的6阶覆盖至12BSF。它与R的BSF六阶统计范围不同，此差异必须在论文中写明。不得在实现中悄悄将2BSF上限改为3阶以追求表面相同的最高频率。

离散化固定采用实际原生FFT频点落入连续区间的集合，边界采用统一半开区间，背景与目标不重复计点。并列峰取最低频率。不得给新增指标加“至少±2 Hz”下限，否则改变原文等宽邻域定义。若某区间没有原生频点，判定窗口条件不支持该指标，记录失败，不用零、邻近峰或插值伪装正常输出。

在当前1720和1797 rpm端点、2 Hz频点间隔下，三类基频第一目标区均有2–4个频点；这只说明区间可采样，不代表检出稳定性已经验证。更换轴承、转速或窗口长度后必须重做区间检查。

## 5. 阈值及未解决条件

### 5.1 已固定

局部检出要求CHNR>0 dB，等于0不检出。

标称显著性水平固定p=0.01。全局阈值形式按原式(28)，使用自由度为2的卡方分布99%分位数9.21034037197618乘随循环频率变化的尺度S。S须与原式(27)及实际解析信号、谱归一化一致。不得用任意噪声均值、median/MAD、训练集经验分位数替换后仍称原指标复现。

这不是窗口级、谐波搜索级或全实验的1%误报率。每个区间取最大值本身涉及多个谱点，多个谐波及多个窗口还引入多重比较。本方案不私自追加Bonferroni等修正，否则不再是原检测规则。实际虚警另用合成对照描述。

### 5.2 未解决条件一：预白化

原文把预白化作为统计阈值的前提，并说明可用线性预测，但在已读取的作者稿中没有核实到可唯一复现的预测阶数、阶数选择、边界处理与滤波实现。不能直接省去预白化后声称统计条件保持，也不能自行指定AR阶数并把它写成作者设置。

当前不锁定一个任意AR阶数。若最后只能自行采用明确的预测阶数选择规则，须将其标为本项目适配，严格沿用的范围仅限C、N数学定义与原检测规则，而非整套预处理复现。预白化是否仅用于C、N，还是用于全部物理描述符，也必须明确后再实施，不能隐性改变R、U。

### 5.3 未解决条件二：SES与噪声尺度的数值对应

原式(7)写为平方包络DFT的模平方，式(27)包含信号均方量和带宽/循环频率尺度。直接将常用库的未归一化FFT模平方与该尺度比较，会产生长度相关的不匹配。

本次独立脚本仅用实高斯白噪声和标准Hilbert约定诊断这一问题。3个长度6000、12000、24000分别取采样率12000、24000、48000 Hz，均为0.5 s；每长度1000个窗口，每窗口检查预先固定的50、100、200、400、800 Hz五个频点，不检查真实轴承数据，不选择分类超参数。

在当前对式(27)的转写约定下：

- 未归一化FFT模平方超过阈值的频点比例为99.9%–100%。
- 除以N后为8.1%–12.0%。
- 除以N平方后为0%。
- 额外诊断的除以2N约定为0.7%–1.6%，与标称1%接近。

最后一项只能说明归一化可以解释数量级差异，不能仅凭接近1%就认定找到了作者实现。特别不能据此声称原论文公式错误。须继续对照出版稿、阈值推导来源或作者实现，说明DFT、解析信号正频率倍增和信号长度的配套约定，才能锁定严格复现实现。

原生频点的点态超阈值诊断，也不是完整的C、N假阳性检查。完整检查还需包括目标区取最大值、递推、局部背景、双阈值和停止规则。
