# 先切窗再随机划分的实验支线


每条记录先切24000点无重叠窗口，再用固定种子20261018按70%/15%/15%随机分配训练、验证和测试。不按负载划分，OR014_3整条排除。共667窗口，实际训练467、验证100、测试100。IR014_0仅2窗，分配1训练、1验证、0测试，例外明确保留，不复制窗口。

采用原固定212维融合模型与原数据单分支。两套协议为纯干净及非配对AWGN。原始阶段融合全样本及10%、20%、50%，单数据分支仅全样本，共66个从头训练模型。现已另行补齐54个数据单分支小样本模型，实验3共120模型。全部选模后统一测试。完整设置见[协议](PROTOCOL.md)。

```powershell
python experiments/CWRU/实验文件/CWRU_V0/experiments/experiment_3/run_window_split.py
python experiments/CWRU/实验文件/CWRU_V0/experiments/experiment_3/infer.py --model 新模型目录/model.pt --input 待推理.npz --output experiments/CWRU/实验结果/CWRU/新推理目录
```

使用现有pytorch_GPU环境。输出必须为项目级experiments/CWRU/实验结果/CWRU中不存在的新独立目录，不覆盖旧372模型或结果。原始data只读。新模型与原固定212维公共权重格式兼容。

每次运行保存windows.csv、record_allocation.csv、class_support.csv、load_support.csv、historical_role_distribution.csv和record_overlap.csv，分别记录实际角色、逐记录分配、类别/负载支持数、历史测试曝光与原记录共享。records.csv只作元数据；每条记录可能包含多种窗口角色，不把该文件误作公共读取器的整记录划分输入。

小样本实际训练数48、95、235，各自另用100个带标签验证窗口。新训练集有126个窗口曾属于历史测试，训练与测试共享38条记录。该实验评价同记录分布下的识别，不用于声称跨负载、跨记录或独立轴承泛化。已有测试曝光与OR014_3事后排除继续披露。

本轮已完成66模型、891组逐次指标、35组汇总混淆矩阵及7张总览和图集，config.json的stage为complete。[正式报告](../../../../实验结果/CWRU/experiment_3/REPORT.md)及模型、预测、指标现已冻结，不自动重训、重新测试或覆盖。当前项目共638模型。

纯干净全样本融合和数据单分支均为100%准确率。AWGN全样本训练后，−4 dB测试融合94.00%、数据单分支95.53%。这些结果未显示强噪声下的融合优势。原报告中的小样本缺少同预算单分支，现已通过独立补充结果完成对照。补充结果不支持AWGN训练后−4dB下的融合优势，不将干净识别的高准确率推广为普遍样本效率优势。
