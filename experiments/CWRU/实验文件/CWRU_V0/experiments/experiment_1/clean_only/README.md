# 纯干净实验

执行 `python train_clean_only.py` 从原始数据训练，并自动生成预测、ACC、宏F1、训练曲线和混淆矩阵。使用 `--data-root` 更换只读数据位置，`--output` 指定不存在的新结果目录。

完整参数与输入说明见[统一使用说明](../../../README.md)。已有模型与[正式报告](../../../../../实验结果/CWRU/experiment_1/clean_only/REPORT.md)保持冻结，新训练保存到独立目录。当前目录的协议文件记录原研究设置，重构后的输出格式以统一说明为准。
