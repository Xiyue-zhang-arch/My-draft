# CWRU V6：方案一六维物理描述符

V6对应已确定保留的方案一，不包含方案二的CHNR、有效谐波数量或预白化。

代码由`experiments/CWRU_Physics6`整体迁移。当前正式结果位于`experiments/CWRU/实验结果/CWRU_V6/small10_20261112_154205`。

## 文件

- `physics.py`：全频带Hilbert平方包络的三项谐波能量占比，以及普通包络的三项自相关周期性。
- `model.py`：独立加载的V3训练引擎和六维物理输入层，保留数据编码器、门控及共享分类头。
- `run.py`、`start.ps1`：10%窗口及跨负载完整实验入口，固定λ=0.3；已完成结果存在时拒绝重复正式启动。
- `report.py`：保存预测、指标和混淆矩阵的复算及汇总。
- `plot_results.m`：MATLAB作图脚本。文件存在不代表已生成图件。
- `PROTOCOL.md`：数据划分、训练、测试和解释边界。

## 已完成范围

窗口划分30个、跨负载120个新融合模型，均含纯干净及AWGN混合训练。引用150个匹配的冻结V3数据单分支。共780份预测、20280行指标和324480个混淆单元，已核验完成。

本次仅整理目录与路径，未重新训练、测试或改动模型权重及概率。检查点内部`fullband_scheme1_six_v1`等配置标识保持不变，以保证原权重严格加载兼容；V6为项目目录版本名称。

## 使用

在项目根目录运行只读计划：

```powershell
./experiments/CWRU/实验文件/CWRU_V6/start.ps1 -Command plan
```

现有10%正式实验已经完成，不重复运行`run`。20%、50%、全样本和方案二均未因目录迁移而获得启动授权。

正式入口依赖原V3/V4的只读数据与训练组件。检查入口还引用V5中的CPU参考函数前六项进行数值对照，不将其新增六项用于V6训练。

迁移前后文件哈希与路径改动记录在[迁移记录](../../../../thesis_document/成果/CWRU_V6_migration/)。正式结果中的训练时代码快照和原始哈希清单沿用历史命名。
