# CWRU V5 39 维 AWGN 跨负载实验

本次阶段报告仅覆盖 20% 与 50% 档。

## 解释边界

V5 混合训练同时改变训练观测、标准化统计和验证选模规则。对照差值评价该整套策略。固定目标记录已有历史测试曝光，完整来源验证集使用额外标签。五种子、噪声实例、固定子集及方向共享记录或模型。标准差描述本设计内的波动。结果适用于当前人工 AWGN、可用记录转速和本数据集。
