# CWRU V5 的 39 维物理描述符

本实现以 CWRU V3 的 212 维融合模型为参照，沿用 V3 的四个滤波范围、窗口、波形预处理和训练接口。V5 每带输出九个特征，末尾追加三个跨带 RMS 对数比，共 $4\times9+3=39$ 维。[40 维设计稿](PHYSICS_FEATURE_DESIGN.md)是此前基于 V4 全频四带的历史候选。两套设计采用不同频带与描述量。

## 信号处理

输入为 48 kHz 驱动端振动信号，每窗 24000 点。进入模型前，沿用 V3 对每窗减均值、除以总体标准差加 $10^{-8}$ 的预处理。提取器接收归一化波形与记录转频，模型用记录的 RPM 除以 60 得到 Hz。无效波形或转速显式报错。既有数据加载器的记录转速及标称值补齐规则沿用 V3。

| 频带 | 振动带通范围 |
|---|---:|
| 1 | 500–3000 Hz |
| 2 | 3000–6000 Hz |
| 3 | 6000–12000 Hz |
| 4 | 12000–20000 Hz |

对各带沿用 V3 的四阶 Butterworth 原型、幅频响应平方与解析频率掩码。带通滤波器总阶数为八。逆变换后取复信号幅值得到包络。频域截断重采样到 3 kHz，两端各裁 75 点并将包络下限设为零，得到 1350 点的 $e_b[n]$，有效长度为 0.45 s。包络减均值后用于自相关，另乘 Hann 窗并作实数 FFT。FFT 模平方为包络功率谱 $P_b[k]$，频点间距为 $3000/1350$ Hz。谱集中度、谱平坦度和主峰位置的频点范围为 $k=1,\ldots,675$，排除直流并纳入 1500 Hz 端点。

## 各组特征

### 四种谐波谱集中度

根据记录转频 $f_r$ 计算各候选频率 $f_m=o_m f_r$。

| 机制 | 阶次 $o_m$ |
|---|---:|
| FTF | 0.39828 |
| BSF | 2.35675 |
| BPFO | 3.58480 |
| BPFI | 5.41520 |

对每种机制取 $h=1,\ldots,6$，仅保留中心频率 $hf_m$ 在有效频率上限内的谐波。目标邻域半宽沿用 V3 的 $\max(2\ \mathrm{Hz},0.015hf_m)$，按实际 FFT 频点中心判断是否纳入。用同一机制各目标邻域的并集 $M_m$ 去重。空邻域对谱集中度的分子贡献为零。令 $\Omega$ 为上述正频点集合，得到

$$R_{b,m}=\frac{\sum_{k\in M_m\cap\Omega}P_b[k]}{\sum_{k\in\Omega}P_b[k]+\varepsilon_R}.$$

分子和分母均使用抬底前的功率。$\varepsilon_R=10^{-12}$，正频点功率之和不超过 $10^{-12}$ 时，该带四个 $R_{b,m}$ 置零。谱集中度表示该带总包络功率落在指定谐波邻域的比例。2BSF 由 BSF 的第二谐波覆盖，转频只用于计算候选频率。Wu 等的式（10）提供了归一化邻域集中度的设计依据，其分子与分母使用包络谱幅值。V5 使用包络功率。 [Wu 等，2026，第 3.2 节](https://doi.org/10.3390/app16168337)

### 加权周期重复性和相位集中度

聚合集合 $A=\{\mathrm{BSF},\mathrm{BPFO},\mathrm{BPFI}\}$。FTF 只进入谱集中度，短窗内的低频周期数量有限。每带按 $R_{b,m}$ 对候选周期响应加权。

$$w_{b,m}=\frac{R_{b,m}}{\sum_{m'\in A}R_{b,m'}+\varepsilon_w},\qquad U_b=\sum_{m\in A}w_{b,m}U_{b,m},\qquad V_b=\sum_{m\in A}w_{b,m}V_{b,m}.$$

- $U_{b,m}$ 沿用 V3 的真实候选自相关分量。对去均值包络补零至两倍长度，计算线性自相关并以零延迟归一化。在 $\ell_j=3000j/f_m$ 附近取最大值，$j=1,2,3$。搜索窗口半宽为 $\max(1,0.02\ell_j)$ 个样点，沿用以四舍五入后延迟为中心的前后 20 点搜索范围及有效正延迟约束。若某个延迟附近没有有效样点，该项填零。三个结果取平均。
- $V_{b,m}$ 沿用 V3 的真实候选相位分量。事件须同时为 7 点邻域局部最大值，且高于包络中位数加 $3\times1.4826$ 倍中位数绝对偏差。两端各三个样点不记事件。对频率倍率 $s\in\{0.985,1,1.015\}$，计算事件相位 $2\pi s f_m n/3000$ 的平均单位向量长度，取三个倍率中的最大值。事件少于 5 个时置零。

$\varepsilon_w=10^{-12}$。三个聚合机制的谱集中度之和不超过 $10^{-12}$ 时，$U_b$ 与 $V_b$ 取零。二者共享同一包络和谱权重，表示在谱响应较强的候选周期下观察到的重复性和相位集中程度。

### 带内形态、谱平坦度和峰位

- $F_{b,1}$ 为高幅值包络能量占比。取包络平方值最大的 $\lceil0.01\times1350\rceil=14$ 项，将这些平方值之和除以该带全部包络平方值之和。分母按原定义以 $10^{-16}$ 为下限。
- $F_{b,5}$ 为包络谱平坦度。在 $\Omega$ 内将功率下限设为 $10^{-16}$，取几何均值与算术均值的比，结果限制在 $[0,1]$。全零谱按该定义的理论值为 1。
- $\rho_b=\frac{f_b^{\mathrm{peak}}}{1500\,\mathrm{Hz}}$ 为包络主峰位置。使用抬底前功率在 $\Omega$ 内寻找最大值，并列时取最低频点。正频点功率之和不超过 $10^{-12}$ 时，峰位置零。主峰位置描述调制频率，候选故障频率、转频或其他调制分量均可形成该峰。

### 跨带相对响应

令 $q_b=\sqrt{\frac{1}{1350}\sum_n e_b[n]^2}$。以第 4 带为参照，追加 $L_i=\log[(q_i+\varepsilon_L)/(q_4+\varepsilon_L)]$，$i=1,2,3$，使用自然对数，$\varepsilon_L=10^{-8}$。对数比表示逐窗归一化、滤波和取包络后各带的相对幅值响应。名义频带有过渡区，三项共享参照，也没有按带宽校正。

## 与 V3 的 212 维特征对应

V3 的每带 53 维由六个候选频率各八项，加五项带级特征构成。候选顺序为 1X、FTF、BSF、2BSF、BPFO、BPFI。表中旧索引为带内零基索引，定位全局列时分别加 $0,53,106,159$。

| V5 描述量 | V3 对应信息 | 变化 |
|---|---|---|
| $R_{b,m}$ | 旧谐波强度列 8、16、32、40 | 使用目标邻域的功率之和除以全谱功率，替换峰背景比均值。谐波覆盖率与偏移频率对照移出。 |
| $U_b$ | 旧自相关列 19、35、43 | 沿用三个真实候选分量，再按谱集中度聚合为一项。 |
| $V_b$ | 旧相位集中度列 21、37、45 | 沿用三个真实候选分量，再按谱集中度聚合为一项。事件率和偏移频率对照移出。 |
| $F_{b,1}$ | 旧列 48 | 沿用带内最高幅值样点的包络能量占比。峭度与峰值因子移出。 |
| $F_{b,5}$ | 旧列 52 | 沿用包络谱平坦度。 |
| $\rho_b$ | 新增 | 从每带包络谱读取归一化主峰位置。 |
| $L_1,L_2,L_3$ | 各带旧列 51 | 用三项相对第 4 带的 RMS 对数比替换四项相对 RMS。 |

## 编码和标准化

固定提取器按窗口在线计算，不使用类别标签，不参与反向传播。训练时仅用当前划分的训练观测估计各维中位数和 IQR。尺度取 $\max(\mathrm{IQR},0.05)$，标准化后裁剪至 $[-8,8]$。验证和测试使用已拟合的统计量。纯干净与 AWGN 拟合观测的组织方式沿用相应 V3 协议。

物理 MLP 为 `Linear(39,64)`、`LayerNorm(64)`、ReLU、Dropout(0.3)、`Linear(64,32)`、`LayerNorm(32)`。仅改变物理输入层宽度，首层比 212 维配置少 11072 个权重。32 维输出进入现有融合门控。V3 自研模型的可训练部件仍是原始波形编码器、物理 MLP、门控和共享分类头。包络分析属于固定物理预处理。旧 212 维权重对应原输入层和原标准化缓冲区，V5 39 维模型需重新训练。

## 解释与评估边界

- 故障频率谱集中度衡量谱线与模板的相符程度。不同候选机制可能共用同一谱点，模板响应可能相关，谱集中度和聚合权重均不表示真实故障概率。
- BSF 的频域描述保留了 2BSF 响应。移出独立的 2BSF 候选也移出了对应周期的独立自相关与相位统计。若后续进行跨负载测试，应单列滚动体召回，特别是 3 HP 到 0 HP。
- 事件相位集中度受窗口长度、事件阈值与检出数影响。理想等高事件可能因浮点舍入而使单窗与批量的事件数不同。低功率带中，数值扰动也可能改变主峰。主峰还可能来自转频或其他调制线。跨带幅值对比可能随负载和振动传递路径变化。测试时需有可用转速。现有 CWRU 记录及固定划分已有历史结果，后续评价属于探索性比较。
- V3 与 V5 的配对比较可评估整套精简方案的效果，包含输入层参数量变化。若 V5 的选定 λ 与 V3 的 0.3 不同，比较也包含辅助损失权重的变化。单个描述量的增量价值需要单独的控制对照。

## 选参和功能检查

沿用 V3 的全负载固定随机窗口划分。纯干净训练 481 窗，验证 103 窗，保留 103 测试窗的划分记录。五档 λ 为 0.01、0.03、0.1、0.3、1.0，各训练五个新融合模型，种子为 1706 至 1710。按五种子最佳验证窗口平均交叉熵的均值取最小，完全同值选较小 λ。选参阶段锁定 λ 后退出，正式跨负载训练须另行审批。

在项目根目录的 `pytorch_GPU` 环境执行以下功能检查。

python -B -m unittest -v experiments.CWRU_V5.test_physics_39
