# CWRU V5 39 维物理描述符纯干净跨负载报告

V5 在固定记录内随机窗口划分上完成 25 个纯干净融合选参模型。五档系数各用五个训练种子。原始五档中，λ = 1.0 的五种子最佳验证交叉熵均值最低，为 5.43963×10⁻⁶。原始选参报告保留全部五档结果。查看原始五档验证结果后，明确融合分类损失系数为 1，原始波形辅助损失系数须小于 1。在已测试且满足该约束的候选中，λ = 0.3 的平均验证交叉熵最低，为 6.11391×10⁻⁶。用户确认正式跨负载实验使用 λ = 0.3。选参阶段只使用验证指标。

本轮用锁定系数从头训练 200 个来源模型。全部来源选模并核验权重后，各模型在另外三个负载上评价，共 600 个模型与目标负载组合。对照只读引用冻结 V3 的 212 维融合和数据单分支，共 1200 个组合。三组模型的目标窗口、保存指标和混淆计数均已从预测重新核对。

V5 固定辅助系数 λ=0.3，V3 212 维融合采用其冻结的 λ=0.3。两个融合模型使用相同的辅助系数。两个融合模型的物理输入层宽度也不同。V3 数据单分支与融合的对照包含物理融合与辅助分类的整体差异。

## 汇总表与解释范围

`comparison_direction_mean_std.csv` 按子集和方向报告五种子波动。`comparison_subset_mean_std.csv` 给出各子集的 12 方向等权结果。`comparison_between_subset.csv` 先求各子集的五种子均值，再报告三个子集间标准差。`pooled_confusion_matrices.csv` 汇总五次预测，`unique_test_support` 记录各方向各类的不同目标窗口数。

全负载选参使用 103 个带标签验证窗口。四来源分别另用 19、39、40、40 个带标签验证窗口选模。小样本比例针对训练窗口，仍使用完整的来源验证集。方向、种子和子集共享记录或模型，汇总标准差描述本设计内的波动。同批目标记录已有历史测试曝光，结果属于本数据集上的探索性跨负载比较。物理特征在测试时依赖记录转速，本次评价限于干净观测。
