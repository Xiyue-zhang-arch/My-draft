# 信号分析 数据使用说明

依据已有数值表和两份settings整理，不重新计算信号或改动原图。没有训练、验证、分类测试集合，不产生分类模型。

## 来源及数量

项目级data/raw/CWRU/48k Drive End Bearking Fault Data中的40个MAT，使用指定DE变量和转速信息。完整路径、采样区间及参考频率见[逐文件使用表](dataset_file_usage.csv)。

|---|---:|---:|---|
|外圈三尺寸，0至3HP|12|120|每记录前10窗、前5秒|
|正常、内圈、滚动体，0至3HP|28|248|IR014四负载各前2窗、前1秒，其他各前10窗、前5秒|
|合计去重|40|368|不累计频带和参考重复|

当前描述性分析包含OR014_3.mat的前10窗，与实验3至6分类纳入规则不同。未因后续分类排除而删除或重算已有分析。

## 行数及重复

外圈window_metrics.csv的480行来自120窗乘4频带。其他类别1472行包含248个不同窗口，B类同一批120窗分别按BSF和2BSF分析，产生额外参考重复后再乘4频带。两表1952行不代表1952个独立窗口。

waveforms_007/014/021使用各相应记录第一个0.5秒窗的前0.1秒，归一化基于完整0.5秒。正常记录跨三图复用，BSF/2BSF复用同一批信号，不新增文件或窗口。不能将图示0.1秒误报为所有频谱分析仅用0.1秒。

包络处理每窗两端各裁0.025秒，有效频谱0.45秒；它与原0.5秒窗口、记录前1秒或5秒范围是不同概念。

## 解释边界

这是干净信号描述，记录内部窗口不是独立轴承重复，不支持人工噪声抗扰或负载因果效应。IR014_0所选DE仅63788点，因此IR014统一仅前2窗；不能隐藏观察时长差异。
