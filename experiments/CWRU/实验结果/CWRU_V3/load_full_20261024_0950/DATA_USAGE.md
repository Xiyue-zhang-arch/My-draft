# V3数据使用

全部40记录687完整窗，原始data只读。逐MAT路径、通道、原始采样点数、丢弃尾部和每个划分及预算的用量见dataset_file_usage.csv，逐类支持数见dataset_support.csv。training_subset_file_usage.csv列出每预算每子集的训练用量，模型选中窗口另存各模型目录。

本轮四来源完整训练73/156/160/160、验证19/39/40/40、目标92/195/200/200。小样本仍使用完整固定验证标签。子集、训练种子、噪声重复及方向均不能作为独立数据集重复。历史测试曝光、训练测试共享记录及全负载选参对迁移结论的限制见PROTOCOL.md。
