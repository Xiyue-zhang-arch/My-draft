# CWRU_V3正式报告

完成80个从头训练的全样本来源模型。统一λ为0.3。本轮12方向、240模型目标组合、3240逐条件指标。不开展小样本。全部训练和选模完成后统一测试。

逐配置五种子均值及样本标准差见evaluation/mean_std.csv。噪声先在模型内平均；本轮只有全样本，不涉及子集间波动。两方法配对差值见paired_mean_std.csv。12方向等权汇总见transfer_equal_direction_mean_std.csv。所有ACC、BA、Macro-F1和四类召回均报告，不以总BA掩盖单类退化。原始及逐行归一化混淆矩阵均保留。

模型成本见computational_cost.csv。单样本延迟包含窗口标准化、在线物理特征和网络，10次预热、50次同步测量，不含磁盘与H2D。Conv1d/Linear FLOPs不含FFT，不能作为完整FLOPs。训练梯度诊断与标准化拟合耗时单独保存在每模型parameters.json。

全部40记录和固定窗口划分已在历史开发中使用，历史测试曝光不会因新目录或重新训练消失。随机窗口训练和测试共享记录，只能评价记录内窗口识别。统一系数由全负载随机窗口验证选择，目标负载已参与方法开发，因此单来源迁移属于探索性评价，不能称严格未见域或独立轴承泛化。

本轮来源0/1/2/3 HP分别另用19/39/40/40个固定验证标签。训练样本数不是总标注预算。五训练种子描述优化随机性。噪声实例、子集和迁移方向不构成独立数据集重复。来源训练和验证共享记录，12方向复用来源模型和目标数据。

两组只能比较融合加辅助分类整体方案与数据单分支，不能分离物理融合和辅助损失各自贡献。固定训练设置不代表文献证明其最优。实际训练量受早停影响。全样本干净验证选出的系数不保证在小样本、噪声或迁移条件下最优，但不再逐条件调整。
