# V3 作者代码对照：纯干净跨负载

DWCN-SDGFD 与 ClassBD-WDCNN 以各自公开实现为基础，具体来源、固定版本、处理和与原实现的差异见本结果目录的 `METHOD_ADAPTATION.md` 和模型训练记录。输入仅采用 V3 固定划分的来源训练窗口和来源验证窗口，不读取目标窗口进行训练与选模。纯干净评价，不新增信号噪声；方法自身对特征的扰动和原方法改动应单独说明。

每方法小样本 4 来源×3 比例×3 固定子集×5 种子，共 180 模型；全样本为 4 来源×5 种子，共 20 模型。逐方法独立运行、结果输出新目录。完整组内模型、最优权重校验完毕后才统一测试对应 3 个其他负载，每个组合保存窗口 ID、标签、概率与逐类指标。来源验证按模型自己的实现确定，必须记录。对照结果只读复用 V3 冻结实验，既有结果不得覆盖。

实际训练目标、模型预处理、输入长度、优化器、超参数和原作者代码差异以各引擎的实现说明和训练记录为准；不能一概描述为普通交叉熵或声称复现原论文指标。每模型输出完整日志，发生失败保留现场，不自动重试。历史已使用相关目标数据开展研究；此对照为固定数据上的探索性实验，不能视作严格未接触目标的确认性实验。

DWCN-SDGFD 固定上游提交 `0719172456687c43e52ea9a0eb09f856ad902b37`，采用24000点输入及 Adam；作者目标标签选模改为来源验证选模。ClassBD 上游提交 `08530497e388ed691936f15d6c55267f277ed270`，先按24000点父窗划分，再对每父窗切12段2048点信号，最后汇总预测；物理项断梯度、分类损失和优化器重置问题经适配修复，采用 AdamW。详细差异见所附方法说明。
