# 原始数据全样本信号分析

日期2026-11-05。范围改为全部40条48kHz驱动端指定DE记录，不按训练、验证、测试角色筛选。它是既有实验后的补充探索；放在论文预处理章节不代表其真实发生于模型训练前。

## 全数据覆盖

原始采样点16,773,271，合计349.443146秒；687个完整0.5秒片段覆盖16,488,000点；所有40记录尾段共285,271点、5.943146秒。原始统计、全记录FFT、Welch与SK覆盖完整记录范围；末段采用末端对齐的完整帧，不补零。周期描述只用全部687个完整段，尾段不伪造成模型输入。

## 规则

每记录全数据均值、标准差、RMS、绝对峰和Pearson峭度保存。原始FFT仅减记录均值，单边实信号能量加权。Welch4096点周期Hann、2048步长、段内去均值，完整展示至24kHz。SK128/256/512点，50%重叠、周期Hann，记录内标准化，复数矩比减2，排除DC/Nyquist；跨记录均值与中位数并列。

全部687段均按自身均值/总体标准差归一化，复用原Evidence，不用训练集拟合、模型权重或预测。22带/13方案，全部6参考均用于全部4类别，标签仅分组；方案汇总沿用IR=BPFI、OR=BPFO、B=2BSF，BSF另存。先记录内汇总，来源类别等权，不把窗口视为独立轴承。

## 结果

- 故障记录全FFT能量约97.281%位于500至6000Hz，原四带合计约97.831%。它是响应分布，不是故障信息覆盖率。
- 同参考全类别对照：BPFI偏移对比正常−2.90dB、IR4.33、OR0.76、B−1.34；BPFO正常−2.50、IR−.54、OR7.11、B−1.28。它支持这批记录中的候选周期关联，但不是盲测或分类增益。
- 2BSF在B类仍为负（−1.72dB），平均周期自相关.032；BSF也弱，不能宣称全部类别机理均清晰。
- SK中位数高值在约5.25k和17–18k，均值最高在23.6–23.8k，不能删掉高频异常后证明20k上界。
- 原方案四带平均PBR11.375dB；下界250/1000分别11.381/11.386；上界18k11.529。因此不能导出exact500/20k或宣称最优。

全数据支持宽范围固定多频带观察的描述性动机。频带仍为原预设设置，不改变历史选带顺序或冻结实验。与上一版549训练窗分析数据重叠，不是独立验证。完整图表、论文表述见PDF，所有参数与科学数值见CSV/settings。

## 记录间反例

IR的四带平均名义对比11/12正值，IR014_0为−3.8487dB，自相关.0092。OR为8/12正值，OR014_0至3均负，自相关.0158–.0470。B的2BSF仅1/12微正，其余负。上界18k相对20k的逐记录均带PBR23提高13下降，ΔPBR20提高16下降，自相关21提高15下降，不能称全面支配。原始FFT最后区间按频点索引包含Nyquist端点，避免浮点频率略大于24000造成遗漏。
