# DWCN-SDGFD 代码来源及适配说明

上游 https://github.com/JC952/DWCN-SDGFD ，固定提交 `0719172456687c43e52ea9a0eb09f856ad902b37`，许可证 MIT。保留作者原 `DWCN.py` 模型和其训练损失，采用原模型推理接口 G_st 与 C_st；中间特征扰动属于原模型训练机制，不对输入信号添加高斯噪声。

原始作者训练脚本存在使用目标标签评价与选模的行为，本次不使用该外层脚本。V3 适配器只输入来源训练与来源验证，按来源验证交叉熵最小保存权重，所有来源模型锁定后才访问目标负载。类别调整为4；输入为每窗独立标准化的24000点振动波形，训练子集及采样按 V3 固定划分，Adam学习率0.0005并使用余弦调度。训练轮数、验证频率及超参数可能不同于原论文，不称为原文结果的精确复现。

一轮真实来源0数据功能检查已通过，含9训练窗与19验证窗；作者模型主、辅助分支和扰动层参数均在合成单批训练中发生有限非零变化。上述检查不计为正式模型或目标域测试。
