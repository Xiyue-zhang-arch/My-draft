# CWRU V4 全频四带与纯干净跨负载实验

## 物理分支

对 48 kHz 采样的驱动端振动信号，预先锁定 0–3、3–6、6–12、12–24 kHz 四个名义滤波范围。首段用截止 3 kHz 的低通，末段用截止 12 kHz 的高通，中间两段用带通。采用四阶 Butterworth 原型和原物理分支的幅频响应平方与解析掩码处理，直流和奈奎斯特端点置零。带通滤波器总阶数为八，边缘低通和高通为四阶。频带存在过渡区。每带沿用 53 维特征，依频率递增排列，共 212 维。

只训练数据单分支和融合加数据辅助分类两种模型。二者输入相同的逐窗口标准化时域波形。融合模型保留原数据骨干、物理分支编码器、门控和共享分类头。各模型均从随机初始化训练。物理特征的 median/IQR 仅由各模型对应的干净训练窗口拟合，IQR 下限和裁剪沿用原规则。

## 统一训练和产物

每模型最多 200 轮，每轮验证，patience 20，验证改善阈值为 1e-6。优化器为 AdamW，初始学习率为 5e-4，权重衰减为 1e-3，batch size 为 32，梯度裁剪为 5。学习率按 200 轮单周期余弦衰减至 1e-5。主分类和辅助分类均用普通交叉熵，标签平滑为 0。验证只对最终分类输出计算普通窗口平均交叉熵。这些数值为固定实验设置。

归档逐轮训练和验证记录、实际训练窗口、配置、最优权重、验证与目标预测、ACC、BA、Macro-F1、各类召回与混淆矩阵。以五种子的均值和样本标准差描述训练随机性，另列固定子集间波动。12 方向汇总时，先在同一种子内对方向等权，再计算种子均值与样本标准差。原始数据和历史模型产物只读，V4 使用独立的结果目录。异常时保留现场。进度见结果目录的 config.json。若进程被外部终止，先核实进程和现场，再处理可能残留的运行锁。

## 解释边界

四带边界来自包含全部 40 条记录及各负载的事后信号扫描。历史测试已经曝光，且统一 λ 通过全负载随机窗口验证选择。因此结果属于这批记录上的探索性跨负载评价。来源验证使用完整的带标签验证集，小样本比例仅指优化器使用的训练窗。方向间存在模型和目标窗口复用，训练种子和固定子集也共享记录，汇总标准差描述的是本设计下的波动。两种模型的对照反映整个融合加辅助分类方法的差异。
