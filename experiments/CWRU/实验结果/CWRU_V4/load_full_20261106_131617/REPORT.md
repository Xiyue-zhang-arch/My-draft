# CWRU V4 全频四带全样本纯干净跨负载报告

四个来源负载各自用完整训练池训练数据单分支和融合加辅助分类模型，每组使用五个训练种子。本轮从头训练40个模型。全部来源模型选模并锁定后，每个模型在另外三个负载上测试，共120个模型与目标负载组合。已从保存的预测复算核对各项指标、混淆矩阵和目标窗口。

融合模型固定辅助损失系数 λ=1。该系数来自此前独立的 V4 选参阶段。五档系数各使用五个训练种子，按五种子最佳验证交叉熵的均值选择，精确相同时选择较小系数。选参只使用固定验证集。本轮物理分支用0–3、3–6、6–12及12–24 kHz四带构造包络特征。

## 验证标签预算与结论范围

此前全负载选参使用103个验证窗口。本轮来源0、1、2、3 HP的训练池分别有73、156、160、160个窗口，另分别使用19、39、40、40个带标签验证窗口选模。来源训练和验证来自同一批来源记录。

四带边界参考了包含目标负载的全数据分析，统一系数也来自全负载随机窗口验证。同批记录已有历史测试曝光，因此这是本数据集内的探索性迁移比较。部分方向共享来源模型或目标窗口，五种子样本标准差反映训练随机性。两组模型的差异反映物理融合与辅助分类的整体效果。
