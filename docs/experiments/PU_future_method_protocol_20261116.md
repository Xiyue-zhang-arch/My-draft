# 后续PU实验五组模型约定

2026-11-16，用户明确要求后续实验仅做等权融合、后端拼接、正确物理调制、振动单模态和电流单模态。此范围用于后续新实验，不追溯更改已完成协议、权重和结果。本次不启动训练、补训或网络推理。

|组别|网络输入|特征与分类|物理描述符使用方式|
|---|---|---|---|
|等权融合|同步振动与电流|独立CNN各64维，等权平均后共享分类头|不使用|
|后端拼接|同步振动与电流|沿用现有PU_0后端残差拼接实现，再进入共享分类头|最终融合64维与8维描述符拼接，经72至17至64残差MLP|
|正确物理调制|同步振动与电流|第三卷积块后调制，继续各分支后得到64维，等权平均及共享分类头|两模态8维描述符共同生成各分支通道缩放，1加0.25乘tanh|
|振动单模态|仅振动|一个原Encoder输出64维，Dropout0.5及Linear64到4|默认不使用描述符或调制|
|电流单模态|仅相电流|一个原Encoder输出64维，Dropout0.5及Linear64到4|默认不使用描述符或调制|

后端拼接保留当前已验证模型的定义，不将它误写成两模态64维向量直接拼成128维。单模态默认采用普通CNN，作为无物理增强的基础对照；不暗中增加单模态有无物理的其他组别。

两个单模态只注册和优化自身编码器及分类头，数据接口只提供自身通道，不读取另一模态的波形、描述符或特征。单模态的波形定标只使用自身通道的训练数据。检查改变未用通道及其描述符时输出不变；仅振动受扰评价下，电流单模态输出应与对应干净条件完全一致。

五组共用后续具体任务的记录划分、窗口身份、训练种子、超参数及固定预算，定标只拟合各自训练集合。匹配可匹配的编码器和分类头初始化，核对实际批次和Dropout流。披露单分支与双分支、条件模块及后端模块的参数量差异，不将容量变化自动解释成模态互补。

后续不自动增加替代频率、普通统计量、仅自身描述符、注意力、门控或其他模型方法。数据协议、类别比例和样本数量由具体实验任务确定，本约定不自动授权增添新的数据设置。用户后续明确修改范围时按新指令执行。

主要比较为等权与两单模态、后端拼接与等权、正确物理调制与等权及后端拼接。五组可以评价当前系统性能和条件加入方式；不含新的频率或统计对照，不能仅据这五组证明正确故障频率的特异机制或描述符等于信息丰富度。既有对照结果及负结果继续保留并如实披露。

实际获授权启动实验后，继续执行持续跟进到训练、评价和独立审计完成并主动报告的约定，不以启动后台进程作为结束。
