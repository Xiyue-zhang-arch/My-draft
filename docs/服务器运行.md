# 在服务器上手动运行实验

将此次更新的代码同步到服务器现有项目。保留原始数据、各实验的数据缓存，以及实验依赖的冻结参照目录。入口以脚本所在目录为项目根目录，不要求服务器的项目路径与原电脑一致。

## 环境

- 建议使用 64 位 Python 3.10 或 3.11。项目本机的通过环境为 Python 3.10、PyTorch 2.11.0 CUDA 12.8。服务器可以使用已经安装的 CUDA 版 PyTorch，以该解释器通过下方的 CUDA 检查为准。需要重新选择构建时，使用 [PyTorch 官方安装选择器](https://pytorch.org/get-started/locally/)。
- 激活已有虚拟环境后，用同一个 `python` 安装其余依赖和运行脚本。依赖文件不包含 PyTorch。
- 训练使用一张可见的 NVIDIA GPU。CWRU V2 及后续训练还会检查 CUDA BF16 卷积。检查命令打印实际 GPU 和可用显存。建议逐个运行实验，将日志、权重和预测写到有足够空间的磁盘。
- `pu-all` 需要能读取 RAR 的 `bsdtar`。Linux 的 GNU `tar` 通常不能读取 RAR。Ubuntu 或 Debian 可安装 `libarchive-tools`，已有可用工具时可通过 `PU_RAR_TOOL` 指定其可执行文件路径。入口会在启动前检查一个原始 RAR 的目录。

```bash
cd /服务器/项目根目录
# 先激活已有虚拟环境
python -m pip install -r requirements.txt
python -m pip check
python run_experiments.py check
```

## 选择并运行

```bash
python run_experiments.py list
python run_experiments.py check pu-all
python run_experiments.py plan pu-all
python run_experiments.py run pu-all
```

`check 实验名` 检查当前解释器、GPU、项目输入和脚本是否可加载。`plan 实验名` 打印将执行的步骤与输出路径，可在没有 GPU 的登录节点使用。`run 实验名` 在前台运行这一项。它默认用时间戳命名新批次，也可以加 `--tag` 指定标签。结果写入现有的 `experiments/数据集/实验结果/版本`，旧批次仍是冻结参照。用 `config.json`、完成标记和报告判断是否完成。部分 CWRU 入口把训练进度写入结果目录中的 `training_console.log`。

| 常用名称 | 对应实验 |
| --- | --- |
| `pu-all` | PU 四工况记录留出 |
| `pu-small` | PU 小样本及类别不平衡 |
| `pu-concat` | PU 直接拼接与单模态 |
| `pu-harmonic` | PU 四谐波跨工况 |
| `cwru-v1` | CWRU 全样本基线 |
| `cwru-v3-full`、`cwru-v3-small` | CWRU V3 全样本和小样本跨负载 |
| `cwru-v4-full`、`cwru-v4-small`、`cwru-v4-half` | CWRU V4 四频带跨负载 |
| `cwru-v5-clean`、`cwru-v5-awgn` | CWRU V5 39 维描述符跨负载 |
| `cwru-v6` | CWRU 六维描述符 10% 实验 |

V0 的六项实验和信号分析、V2 各现行运行入口、V3 的各比较方法及其样本范围都可用 `list` 查看。V2 的旧诊断流程、V3 的一次性续跑工具和 V5 的中止批次接力属于原批次历史。V5 AWGN 的现行入口执行完整预算；分批归档记录见 [CWRU 实验说明](../experiments/CWRU/实验说明.md)。

前三个 PU 入口自动准备或验证四谐波缓存，运行功能预检，再训练、评价和审计。已有的新版缓存必须与当前代码和冻结数据校验记录匹配。缓存失配时，将该实验下的 `data/harmonic_calibration` 移到独立留存位置后，才能在原位置生成新缓存。不要移动 `data/prepared`、`data/source_20261115_a` 或项目级 `data/pu_shared/prepared_inputs`。

PU 四谐波跨工况在服务器上核对窗口、标签和批次顺序，并在预设容差内比较冻结特征。运行配置保存初始化和 CUDA 随机状态是否与原机器匹配。不同硬件上的结果属于同一划分下的新计算，不能声称逐位复现原权重或与旧模型共享完全相同的 CUDA 随机过程。

## 输入所在位置

| 数据 | 需要保留的内容 |
| --- | --- |
| CWRU | `data/raw/CWRU/48k Drive End Bearking Fault Data` 的 40 个 MAT 文件。V2 至 V6 的部分批次还读取既有划分、配置、权重和预测，按 `check 实验名` 提示检查相应结果目录。 |
| PU | `data/raw/PU` 下清单列出的原始 RAR，各实验现有 `data` 下的划分与输入缓存，项目级 `data/pu_shared/prepared_inputs`。四谐波跨工况还需要原正式批次的模型轨迹、定标、指标及完成记录。 |

若检查报告缺少文件，先核对同步范围。只同步脚本和汇总报告不足以运行复用冻结参照的实验。
