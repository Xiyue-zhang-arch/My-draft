# 物理特征文献依据对照

本表用于核对论文第 3 章的来源。表中“相关依据”只表示文献支持相应的物理现象、统计方法或设计思路；它不自动证明本文实现的具体算法与参数出自该文献，也不单独证明特征有效。

| 论文内容 | 可核验的相关依据 | 本文实现中需要单独说明的部分 |
| --- | --- | --- |
| 轴承运动学故障频率、转速和几何参数 | [Randall 与 Antoni，2011](https://doi.org/10.1016/j.ymssp.2010.07.017)，论文参考文献 [1] | 本研究的六个固定阶次、具体轴承几何参数，以及缺失转速时采用的标称值，是数据与实现选择。 |
| 多频带、包络解调与谐波 | [Duan 等，2018](https://doi.org/10.3390/s18051466)，[1] 和 [50] | 文献的频带选择与源分离过程不同于本文。四个固定频带、滤波阶数、重采样、截边、窗函数及六阶谐波是本研究设置。 |
| 谐波强度 | [Randall 与 Antoni，2011](https://doi.org/10.1016/j.ymssp.2010.07.017) 和 [Duan 等，2018](https://doi.org/10.3390/s18051466)，[1]、[50] | 峰值和局部背景的比值及六阶平均是本文具体定义；局部搜索容差不是上述文献给出的通用标准。 |
| 谐波覆盖率 | 同 [1]、[50] 对频率和谐波的分析 | 六阶中超过三倍背景的比例是本研究的汇总规则，不能将该阈值说成经文献验证的最优值。 |
| 谐波对比度 | 同 [1]、[50] 对谐波及其背景的讨论 | 候选阶次与六个偏移阶次比较，并减去最大参照值，是本文经验性构造，并非统计显著性检验。 |
| 周期重复性和重复对比度 | [Moshrefzadeh 与 Fasana，2018](https://doi.org/10.1016/j.ymssp.2017.12.009)，[Antoni，2007](https://doi.org/10.1016/j.jsv.2007.02.029)，[51]、[52] | 文献支持通过自相关或循环统计研究周期性。本文计算去均值包络的归一化自相关，并选择三个延迟和偏移参照；这不等同于文献中的自相关平方包络或循环谱方法。 |
| 相位集中度 | [Leahy 等，1983](https://doi.org/10.1086/161288)，[53] | 该研究来自天体物理周期检测，支持事件相位向量的数学思路；本文使用的是平均相位向量长度，不声称已实施其统计检验。 |
| 相位对比度、事件率 | 事件相位向量的基础见 [53]；稳健尺度见 [Rousseeuw 与 Croux，1993](https://doi.org/10.1080/01621459.1993.10476408)，[54] | 事件提取、七点局部极大、三倍 MAD、至少五个事件、偏移参照及事件率上限是本文经验规则。MAD 的 1.4826 比例具有正态分布下的尺度校正背景，不证明包络分布为正态。 |
| 峭度、峰值因子、均方根 | [Randall 与 Antoni，2011](https://doi.org/10.1016/j.ymssp.2010.07.017)，[1] | 本文对包络而非直接对原始波形计算，并对峭度和峰值因子取 log1p；未单独验证该变换的贡献。 |
| 顶部 1% 能量占比 | 可借助 [1] 中冲击和幅值统计的背景理解该指标 | 具体取最大 1% 样点的能量比例属于本研究构造，现有引用不证明 1% 为最佳阈值。 |
| 对数相对均方根 | 均方根的物理统计背景见 [1] | 除以各频带 RMS 之和及取对数是本研究构造；不能写成文献直接提出这一具体指标。 |
| 谱平坦度 | [Bardeli，2011](https://www.isca-archive.org/chime_2011/bardeli11_chime.pdf)，[55] | 文献属于音频源分离，直接支持谱平坦度的数学定义，不证明它对本文轴承分类具有独立效果。 |
| 中位数和四分位距标准化 | [scikit-learn RobustScaler 文档](https://scikit-learn.org/1.7/modules/generated/sklearn.preprocessing.RobustScaler.html)，[56] | 训练子集内拟合、尺度下限 0.05、截断至正负 8 和含噪观测的拟合方式是本文协议；未实施参数敏感性测试。 |
